# Security

Git Auto Deploy receives code (a theme) over the internet and puts it live on your site, so
reports of security problems are very welcome.

## Reporting a vulnerability

Please do not open a public issue. Report it privately instead: open the repository's
**Security** tab and choose **Report a vulnerability**. Include what you found, how to
reproduce it, and which version you tested.

## Supported versions

Security fixes go into the latest release only.

## How deploys are protected

See [Security](docs/how-it-works.md#security) in the guide: what is signed, what the plugin
checks in every zip, and what someone holding the deploy secret can do.
